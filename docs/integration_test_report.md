# Отчёт об интеграционном тестировании (T08)

Дата: 24–25.10.2026. Ветка `feat/insight-mvp` (PR #48). Ответственный: Тимур.

## Окружение

- macOS, Docker Desktop 29.0.1, `docker compose up --build`: `postgres` (17-alpine), `backend` (Go-шлюз),
  `ai` (FastAPI), `web` (nginx + React). Все запросы — через UI-origin `http://localhost:3000` (nginx → шлюз → AI).
- Данные: реальные CSV кейса в `data/raw/` (924 профиля при пороге 5 млрд + 2 помеченных синтетических пограничных
  случая), 9 документов аналитики банка (219 фрагментов), новости — офлайн-снимок (200) + живой импорт RSS
  (в ленте рассматривалось до 448 публикаций).
- LLM: шлюз организаторов, модели `z-ai/glm-5.3-flash` (план), `google/gemma-4-26b-a4b-it` (извлечение события),
  `qwen/qwen3.6-35b-a3b` (инсайт, чат). Режим `llm` подтверждён в `GET /api/v1/system/status`.

## Найденные дефекты и исправления

| Дефект | Где проявился | Исправление |
|---|---|---|
| Qwen тратил весь `max_tokens` на «размышления», ответ без JSON | первый живой вызов LLM | `reasoning: {enabled: false}` по умолчанию (`LLM_REASONING`), повтор без параметра при 400 |
| Обрывы TLS до шлюза LLM через прокси/VPN | живые вызовы | до 3 повторов при ошибке соединения |
| Ошибки валидации в формате FastAPI `{"detail": ...}` | `POST /insights` без `news_id` | единый формат `{"error": ...}`, код 400 |
| Сообщения разных изданий об одном событии не склеивались | лента (атака на склад в Омске, решение ЦБ) | коэффициент перекрытия заголовков + склейка однотипных макрособытий за сутки, первоисточник (ЦБ) — представитель |
| Чат приписывал Альфа-Банку рекомендацию, которой нет в материалах | ответ на «Как это повлияет на обслуживание кредитов?» | запрет в промпте + фильтр фраз «банк рекомендует/советует» без фрагмента аналитики |
| Режим правил не находил механизмов для новости о ставке без направления | экран инсайта | общие механизмы для ставки; распознавание отрицания («снижения не будет» → пауза) |
| В чате цитировалась распознанная таблица (набор цифр) | чат в режиме правил | фрагменты `table_like` не цитируются |
| Модель сама ставила позиции банка статус «устарела» | инсайт LLM | статус вычисляется кодом по датам документов |
| «Цитатой» банка служило название документа | инсайт LLM | цитата проверяется только по тексту фрагмента |
| Порт фронтенда: compose `3000:80`, nginx слушает 3000 | `docker compose up` | `3000:3000` |
| Ложная высокая значимость зарубежной новости (Starlink) через триггер «ограничен» | лента U_57706 | лексикон: «ограничен/запрет» только рядом с экспорт/импорт/пошлин/санкц; понижение для зарубежных рынков |

## Известные ограничения (не блокируют сценарий)

- Длительность инсайта в режиме LLM — 30–60 с; UI показывает живой прогресс шагов, повторный запрос отдаётся из кэша.
- Модель иногда делает осторожные предположения из флага ФТС («потенциальная зависимость от импорта»), хотя
  направление ВЭД в данных не указано; правило в промпте есть, валидатор такие формулировки пока не ловит.
- Коммерсантъ из Docker периодически не отвечает (TLS timeout сети) — остальные источники импортируются.
- Загрузка новости по URL на этой машине требует `FETCH_ALLOW_CIDRS=240.0.0.0/4` (VPN подменяет DNS fake-IP).
- Проверка на ноутбуке разработчика; прогон на чистом клоне вместе с другим участником — в T09.
