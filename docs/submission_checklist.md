# Чек-лист сдачи

Сверка с разделом «Формат сдачи решения» кейса (стр. 8). Статусы: **Готово** — есть в репозитории; **Проверить** — есть, но перед дедлайном нужна сверка; **Сделать** — действие в день сдачи.

## Обязательные материалы

| № | Требование кейса | Статус | Где лежит / что сделать |
|---|---|---|---|

## Проверки перед дедлайном

- [ ] Чистый клон → `docker compose up --build` → UI открывается на `http://localhost:3000`, `GET /ready` возвращает `ready`.
- [ ] На синтетике (без `data/raw`) сквозной сценарий проходит: лента → инсайт → трасса → чат → 403 для чужого клиента.
- [ ] С реальными CSV: `U_1595` и `U_8167` присутствуют, а значимость новости о ставке у них различается.
- [ ] С ключом LLM: `/system/status` показывает `mode: llm`, `models_allowed` у всех ролей равно `true`, инсайт формируется в режиме `llm`.
- [ ] Тесты: `pytest` (ai), `go test ./...`, `npm run build` — без ошибок (команды в README, раздел «Тесты»).
- [ ] В истории git нет `.env`, ключей и реальных CSV: `git log --all --stat | grep -E '\.env$|data/raw|data/generated'` возвращает пусто, поиск по `sk-` в `git log -p` ничего не находит.
- [ ] Тег или хэш зафиксирован, доступ `alfa-hack-2026` выдан, репозиторий приватный.
