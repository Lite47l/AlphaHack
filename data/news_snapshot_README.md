# news_snapshot.json — контрольная выгрузка реальных новостей

Файл нужен для офлайн-прогона сервиса и как тестовый набор. Все записи пришли
из публичных RSS-лент: заголовки, тексты, ссылки и даты взяты из лент. Мы
только очищаем HTML и приводим даты к одному формату. Ничего не дописано и не
перефразировано.

## Когда и как собрано

- Время сбора: `generated_at` = 2026-10-24T20:22:59+03:00.
- Окно отбора: 14 дней до момента сбора. Фактически записи датированы
  с 2026-10-12 по 2026-10-24 (больше всего за 23–24 октября).
- Скрипт: `scripts/fetch_news_snapshot.py`, только стандартная библиотека Python 3.12.
- Команда:

```
python3 scripts/fetch_news_snapshot.py --out data/news_snapshot.json --save-raw <каталог>
```

  Повторный отбор без сети по сохранённым лентам (результат детерминирован):

```
python3 scripts/fetch_news_snapshot.py --from-raw <каталог> --now 2026-10-24T20:22:59+03:00
```

  Сырые XML-ленты в репозиторий не кладём.
- Параметры по умолчанию: `--days 14 --target 200 --nonbiz 25 --dup-clusters 8 --max-source-share 0.3`.
- HTTPS: сертификаты всегда проверяются. Берём `/etc/ssl/cert.pem` и, если они
  есть, дополнительные системные бандлы (brew ca-certificates, бандл python.org,
  `Russian_Trusted_Root_CA.cer` из репозитория). Нужно это потому, что в
  `/etc/ssl/cert.pem` на macOS нет корня HARICA, которым подписан cbr.ru.
- Обработка: из `<item>` берём title, link, description и pubDate, а если в
  ленте есть полный текст (yandex:full-text, content:encoded, rbc_news:full-text),
  то и его. Очищаем HTML и сущности, переводим дату в ISO 8601 с таймзоной
  (если зона не указана, считаем её московской). Дубли удаляем по
  нормализованному URL: схема https, без фрагмента и utm-меток.

## Формат

```
{"generated_at": "<ISO>",
 "sources": [{"name", "url", "fetched", "kept", "error"}],
 "items":   [{"title", "summary", "url", "source_name", "published_at"}]}
```

- `summary`: очищенный текст из description или полного текста (берём тот, что
  длиннее), не больше 4000 символов. Если текст обрезан, в конце стоит «…».
- `items` отсортированы по `published_at` от новых к старым. Файл в UTF-8,
  `ensure_ascii=False`.

## Правила отбора

Отбор по ключевым словам служит только для того, чтобы набрать выборку с
перекосом в экономику. Это не классификатор продукта, и разметка тем в файл не
пишется.

1. Банк России: берём все записи обеих лент ЦБ за период (20 шт.). Среди них
   пресс-релиз «Банк России принял решение сохранить ключевую ставку на уровне
   14,00% годовых (23.10.2026)».
2. Одно событие в разных изданиях: 8 кластеров (24 записи). Записи объединяются
   в кластер по сходству заголовков, если их выпустили разные издания с разницей
   не больше 3 дней. Вот эти кластеры:
   - решение по ставке 23.10 (ЦБ, Коммерсантъ, Лента.ру);
   - ожидания по ставке (Коммерсантъ, Banki.ru, Лента.ру, Ведомости);
   - кредитные каникулы для продавцов Wildberries (Коммерсантъ, Banki.ru, Лента.ру, Ведомости);
   - атака на логистический центр Ozon в Омске (РБК, Ведомости, РИА);
   - экспорт дизеля (Коммерсантъ, Лента.ру, Ведомости);
   - заявления Набиуллиной о финансовой стабильности (Коммерсантъ, Лента.ру, Ведомости);
   - онлайн-продажа вина (Коммерсантъ, Ведомости, Лента.ру);
   - саммит газового форума (Коммерсантъ, Ведомости).

   При тематическом отборе в выгрузку попали и другие пары: про льготную
   ипотеку, курс доллара и урожай картофеля, а также концерт Галкина среди
   небизнесовых. Ещё есть пары с разными URL внутри одного издания: новость и
   газетная заметка Коммерсанта, например про урожай картофеля.
3. Небизнесовые новости: 25 записей (спорт 9, культура 8, происшествия 8).
   Отбираются по ключевым словам заголовка и рубрике RSS, если в заголовке нет
   бизнес-тем. Нужны для проверки фильтрации. Ещё несколько общих новостей
   (политика, протесты) попали в выгрузку как пограничные случаи.
4. Экономика и бизнес: остальные записи добираются по кругу по темам: ставка ЦБ,
   инфляция, курс, нефть и топливо, металлы и уголь, агро, розница, рынок труда,
   бюджет и налоги, кредиты и облигации, санкции и экспорт/импорт, логистика,
   стройка и ипотека, компании. Одно издание даёт не больше 30% записей.
   Сначала берутся записи с текстом, затем более свежие.

## Ограничения

- RSS отдаёт анонсы, а не полные статьи. У 76 записей из 200 `summary` пустой,
  потому что в ленте нет описания: Лента.ру, РИА Новости, общая лента Ведомостей
  и часть лент ЦБ. У Ведомостей, Коммерсанта и Banki.ru обычно один-два
  предложения. Полный текст есть только у пресс-релизов ЦБ и у РБК.
- Ленты короткие: у большинства изданий они покрывают только последние 1–5
  дней. Поэтому выгрузка смещена к 22–24 октября и 14 дней фактически
  покрывают только ленты ЦБ и Ведомостей.
- Права на тексты принадлежат изданиям и Банку России. Выгрузка используется
  только для тестирования и демонстрации на хакатоне и не публикуется как
  контент. Ссылка `url` ведёт на первоисточник.
- Если запустить скрипт повторно, получится другой набор, потому что ленты
  обновляются. Именно этот снимок можно воспроизвести только по сохранённым
  сырым лентам (`--from-raw`).
