## 5. Языковые модели (внешний сервис организаторов)

Модели не входят в репозиторий и не распространяются. Обращения идут по OpenAI-совместимому API организаторов хакатона (`LLM_BASE_URL`) с ключом команды, на условиях кейса (Приложение 3) и с дневным лимитом. Код допускает только модели из списка кейса (`ai/app/config.py:ALLOWED_MODELS`), любую другую модель отклоняет.

| Модель (как в кейсе) | Имя у провайдера | Роль в решении |
|---|---|---|
| GLM-5.3-Flash | `z-ai/glm-5.3-flash` | Планировщик агента, переформулировка запросов |
| Gemma 4 26B A4B | `google/gemma-4-26b-a4b-it` | Извлечение структуры события |
| Qwen3.6 35B A3B | `qwen/qwen3.6-35b-a3b` | Генерация инсайта, доработка, ответы в чате |
| DeepSeek-V4.1-Flash, Qwen3-VL-30B-A3B-Instruct, Kimi-K2.6 | `deepseek/deepseek-v4.1-flash`, `qwen/qwen3-vl-30b-a3b-instruct`, `moonshotai/kimi-k2.6` | Разрешены allowlist, по умолчанию не используются |

Сторонние AI-сервисы, готовые агентные фреймворки и embedding-модели не используются. Логика поиска, ранжирования, агента и проверки реализована командой.

## 8. Смоделированные интеграции

- **Интерфейс интернет-банка Альфа-Бизнеса** (`frontend/`) — демонстрационный макет, сделанный командой для показа точки входа и сценария. Он не связан с реальными системами банка, не использует их API и не обрабатывает реальные учётные записи.
- **Счета и остатки на главной странице** — демо-данные, в интерфейсе отмечены «демо-данные».
- **«Предложение банка»** в инсайте — шаблонный текст по типу канала влияния (`ai/app/mechanisms.py:OFFERS`), помечен как предложение банка. Это не оферта и не результат реального скоринга.
- **Пользователь и роль.** Вход не реализован. Клиент выбирается переключателем, роль по умолчанию — финансовый директор. Заголовок `X-Client-Id` имитирует контекст сессии интернет-банка.
